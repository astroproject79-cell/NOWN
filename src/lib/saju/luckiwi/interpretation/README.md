# 해석 엔진 (Interpretation Engine)

> 사주 분석 데이터를 "삶의 구조 설명서"로 변환하는 스토리텔링 엔진

## 핵심 철학

```
"분석이 아니라 이해, 나열이 아니라 연결, 예언이 아니라 가능성"
```

이 엔진은 사주 분석 결과를 단순히 나열하는 것이 아니라,
하나의 **일관된 서사(Narrative)** 로 엮어 전달합니다.

## 스토리텔링 5원칙

### 1. 중심 메타포 일관성 (Central Metaphor Consistency)

처음 설정한 이미지가 문서 전체를 관통해야 합니다.

```
예: "차가운 칼날" 메타포 설정 시
✓ "온기가 들어오면 제련된다"
✓ "불을 만나 녹슬지 않게 된다"
✗ "씨앗이 싹을 틔운다" (메타포 혼재)
```

### 2. 부정의 역설적 재해석 (Paradoxical Reframing)

모든 약점은 "아직 때가 아닐 뿐"으로 전환합니다.

```
예:
- "무재사주 = 인연 박함"
  → "운에서 들어올 때 가장 확실히 내 것이 된다"

- "관성 없음 = 직장운 약함"
  → "조직에 얽매이지 않는 자유로운 삶의 구조"
```

### 3. 영웅의 여정 구조 (Hero's Journey Structure)

사주 해석을 서사적 흐름으로 구성합니다.

```
1. 평범한 세계 → 태어난 환경 (년주, 월주)
2. 소명의 부름 → 삶의 과제 (격국, 용신)
3. 시련 → 구조적 어려움 (충, 형, 해)
4. 멘토와의 만남 → 도움의 요소 (인성, 귀인)
5. 변환 → 운에서의 변화 (대운, 세운)
6. 귀환/보상 → 미래 전망
```

### 4. 공감적 인정 (Empathetic Validation)

사용자의 고통을 인정하고 "당신 탓이 아니다"라는 메시지를 전달합니다.

```
예:
- "이미 충분히 열심히 살고 있습니다"
- "능력보다 먼저 역할이 주어지고, 보상보다 의무가 앞서는 구조입니다"
- "당신이라는 거대한 바위가 너무 차가워 곁에 머물 수 없었던 것입니다"
```

### 5. 실용적 조언 포함 (Actionable Advice)

철학적 해석 + 구체적 행동 지침을 함께 제공합니다.

```
예:
- "규칙적인 생활, 기록하고 정리하는 습관"
- "선택적으로 돕고, 선택적으로 거절하는 것도 성숙한 책임"
```

## 메타포 데이터베이스

### 일간별 기본 이미지

| 일간 | 기본 이미지 | 긍정 키워드 | 부정 키워드 |
|------|------------|------------|------------|
| 甲木 | 큰 나무, 대들보 | 곧음, 성장, 우직함 | 고집, 융통성 부족 |
| 乙木 | 꽃, 덩굴, 풀 | 유연함, 적응, 아름다움 | 의존, 나약함 |
| 丙火 | 태양, 햇빛 | 밝음, 드러남, 에너지 | 소진, 성급함 |
| 丁火 | 촛불, 등잔불 | 섬세함, 온기, 집중 | 불안정, 소심함 |
| 戊土 | 산, 언덕, 대지 | 안정, 포용, 중심 | 완고, 둔함 |
| 己土 | 논밭, 정원 | 양육, 수확, 기다림 | 소심, 의심 |
| 庚金 | 검, 도끼, 원석 | 결단, 날카로움, 제련 | 냉정, 무정 |
| 辛金 | 보석, 바늘, 칼날 | 정교함, 빛남, 예리함 | 예민, 까다로움 |
| 壬水 | 강, 바다, 큰물 | 흐름, 지혜, 깊이 | 변덕, 방랑 |
| 癸水 | 비, 이슬, 안개 | 스며듦, 적셔줌, 변화 | 우울, 음침함 |

### 계절별 상태 변형

| 계절 | 특징 | 조후 필요 |
|------|------|----------|
| 봄 (寅卯月) | 성장기, 시작, 생기 | 목→금으로 제어, 화→수로 조절 |
| 여름 (巳午月) | 전성기, 빛남, 활동 | 화→수로 냉각, 토→목으로 소통 |
| 환절기 (辰戌丑未) | 전환기, 저장, 준비 | 토→목으로 유연, 금→화로 활성 |
| 가을 (申酉月) | 결실기, 수확, 날카로움 | 금→화로 제련, 목→토로 안정 |
| 겨울 (亥子月) | 휴식기, 저장, 잠재 | 수→화로 온기, 금→화로 제련 |

### 조합 예시 (庚金의 경우)

```
庚金 + 봄   = "봄에 나온 칼, 나무를 베어 쓰임을 찾음"
庚金 + 여름 = "용광로 속 금속, 제련되어 가치가 드러남"
庚金 + 가을 = "제철을 만난 칼, 날이 서고 빛남"
庚金 + 겨울 = "얼어붙은 칼날, 차갑고 쓰임을 못 찾음"
```

## 삶의 유형 분류

| 유형 | 조건 | 특징 키워드 |
|------|------|------------|
| **자수성가형** | 인성약 + 비겁강 또는 신약 + 식상과다 | 책임, 고단함, 정신력 |
| **부모덕형** | 인성강 + 관성유정 | 지원, 안정, 학업 |
| **귀인형** | 천을귀인 + 정관정인 | 도움, 인복, 순탄 |
| **창업형** | 재성강 + 식상생재 | 사업, 재물, 활동 |
| **전문가형** | 상관 + 편인 또는 식신 + 정인 | 기술, 전문성, 깊이 |
| **리더형** | 정관 + 인성 | 명예, 조직, 책임 |
| **예술가형** | 식상강 + 재성약 | 창작, 표현, 자유 |
| **학자형** | 인성과다 + 식상유정 | 연구, 사색, 지식 |

## API 사용법 (예정)

```typescript
import { generateStory } from './interpretation/story';
import { analyzeSaju } from './analysis';

// 1. 사주 분석
const analysis = analyzeSaju({
  year: 1990,
  month: 12,
  day: 15,
  hour: 14,
  gender: 'male'
});

// 2. 스토리 생성
const story = generateStory(analysis, {
  template: 'standard',      // 문서 템플릿
  depth: 'detailed',         // 상세 수준
  tone: 'friendly',          // 톤
  includeYearFortune: true,  // 올해 운세 포함
  year: 2026                 // 운세 대상 연도
});

// 3. 결과 출력
console.log(story.fullText);
```

## 기여 가이드

### 서사 블록 추가 시
1. `narrative/data/blocks/` 에 JSON 파일 추가
2. `conditions` 필드에 적용 조건 명시
3. `priority` 설정 (구체적일수록 높은 값)
4. `meta.source` 에 출처 기록
